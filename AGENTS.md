# AGENTS.md

Guidance for AI coding agents (and human contributors) working in this repository.

## Repository overview

`jumpID` is an R package for identifying and analyzing jump dispersal (vs. diffusive spread and secondary diffusion) in biological invasions from species occurrence data.

## Repository structure

- `R/` — package source functions (e.g. `find_jumps.R`, `find_jumps_wrapper.R`, `find_secDiff.R`, `find_thresholds.R`, `group_jumps.R`, `attribute_sectors.R`, `rarefy_groups.R`).
- `man/` — auto-generated Rd documentation (generated by roxygen2; do not hand-edit).
- `vignettes/` — package tutorials in R Markdown (`.Rmd`) with rendered PDFs, e.g. `010_Jump_list.Rmd`, `011_Figures_jump_list.Rmd`, `020_Decreasing_calculation_time.Rmd`.
- `docs/` — rendered pkgdown website output (generated; do not hand-edit).
- `DESCRIPTION` — package metadata (dependencies, license, version).
- `NAMESPACE` — auto-generated by roxygen2; do not hand-edit.
- `_pkgdown.yml` — configuration for the pkgdown documentation site.
- `jumpID.Rproj` — RStudio project file.
- `LICENSE.md` — Modified MIT License (non-commercial use + citation requirement).

## Build / validation steps

This is a standard R package. After making changes to files in `R/` (including roxygen `#'` comments):

1. Regenerate documentation and `NAMESPACE`:
   ```r
   devtools::document()
   ```
2. Install and load the package locally:
   ```r
   devtools::install()
   ```
3. Run package checks before committing:
   ```r
   devtools::check()
   ```
4. If vignette content changed, re-knit the affected `.Rmd` file(s) in `vignettes/`.

## Conventions

- Function documentation uses roxygen2 (`RoxygenNote: 7.3.2` in `DESCRIPTION`). Add/update roxygen comments above functions in `R/` rather than editing `man/*.Rd` or `NAMESPACE` directly.
- Package dependencies are declared in `DESCRIPTION` under `Imports`; add new dependencies there when introducing new package usage.
- Tutorials/examples live in `vignettes/` as numbered `.Rmd` files (e.g. `010_`, `011_`, `020_`) with a matching rendered `.pdf`.
- The documentation website (`docs/`) is built via pkgdown from `_pkgdown.yml` and should not be edited by hand — regenerate via `pkgdown::build_site()` if needed.
- License is `file LICENSE.md` (Modified MIT, non-commercial + citation required) — see `DESCRIPTION` and `LICENSE.md`.
